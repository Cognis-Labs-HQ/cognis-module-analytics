# Cognis Analytics

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · **日本語**

Cognis 向けの、プライバシーに配慮した利用状況の分析と管理レポート機能です。サードパーティーの分析サービスを導入することなく、登録傾向、アクティベーション、アカウントの健全性、ロール分布、モジュール所有のイベントを追跡できます。

このリポジトリは自己完結型の Cognis 拡張モジュールです。モジュールマーケットプレイスからインストールするか、設定済みの外部モジュールディレクトリに配置してください。設定、ケイパビリティ、ルート、運用方法については [`docs/standard.ja.md`](docs/standard.ja.md) を参照してください。同等のドイツ語、英語、インドネシア語版も同じ場所にあります。

## 分析範囲

- アカウント総数、有効・無効状態、7 日間のアクティビティ、30 日間の休眠状況
- 設定可能な 7 日、30 日、90 日の登録時系列
- 16 KiB のリクエスト上限を備えた、プライバシーに配慮したカスタムイベント収集
- イベント量、ユニークアクター、イベント種別の概要
- ホストの認可で保護された管理ダッシュボードと CLI アクセス

## はじめに

```sh
npm install
npm test
npm run check:manifest
```

マニフェストは `ui.stringsBaseUrl` を通じてモジュール所有の言語バンドルを公開するため、Analytics UI が読み込まれる前に Cognis がマーケットプレイスのメタデータをローカライズできます。
