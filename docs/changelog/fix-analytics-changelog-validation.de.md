# Analytics-Aktivierung reparieren

**Feature-Zweig:** fix-analytics-changelog-validation

## Lokalisierte Changelog-Überschriften korrigieren

Die deutschen und indonesischen Commit-Überschriften des Eintrags zur strikten UI-Lokalisierung entsprechen wieder der bestehenden Dokumentationskonvention. Alle vier Sprachvarianten erhalten einen einheitlichen Abstand vor der Commit-Liste. Damit blockiert die Dokumentationsprüfung die Aktivierung von Analytics nicht mehr; die strikten XML-Lokalisierungsregeln bleiben erhalten.
