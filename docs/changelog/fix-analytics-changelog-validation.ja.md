# Analyticsの有効化を修正

**機能ブランチ:** fix-analytics-changelog-validation

## ローカライズされた変更履歴の見出しを修正

厳格なUIローカライズの変更履歴で、ドイツ語とインドネシア語のコミット見出しを既存の文書規約に合わせます。4言語すべてでコミット一覧の前の空行を統一します。厳格なXMLローカライズ規則を維持したまま、Analyticsの有効化を妨げていた文書検証の失敗を解消します。
