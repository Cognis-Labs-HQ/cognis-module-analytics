# Menyelaraskan changelog dan instruksi AI

**Cabang Fitur:** feature-align-changelog-structure-with-pull-request-187

## Struktur changelog yang konsisten

Instruksi repositori kini menetapkan keluarga changelog yang dilokalkan, metadata cabang fitur, poin perubahan terperinci, dan tautan commit kanonis. Dengan demikian, Cognis dapat menemukan entri modul eksternal secara andal dan menyajikannya pada antarmuka rilis.

## Aturan dokumentasi yang dapat diverifikasi

Pengujian dokumentasi kini menangani changelog secara terpisah dari dokumentasi standar serta memvalidasi varian bahasa, metadata, rincian perubahan yang bermakna, dan tautan commit. Berkas instruksi Copilot khusus menyediakan aturan yang sama untuk kontribusi berbantuan AI.
