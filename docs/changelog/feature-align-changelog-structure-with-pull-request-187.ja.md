# 変更履歴とAI向け指示の整合

**機能ブランチ:** feature-align-changelog-structure-with-pull-request-187

## 一貫した変更履歴の構造

リポジトリの指示で、ローカライズされた変更履歴ファミリー、機能ブランチのメタデータ、詳細な変更点、正規のコミットリンクを定義しました。これにより、Cognisは外部モジュールの項目を確実に検出し、リリース画面に表示できます。

## 検証可能なドキュメント規則

ドキュメントテストでは、変更履歴を標準ドキュメントとは別に扱い、言語別ファイル、メタデータ、内容を伴う変更点、コミットリンクを検証するようになりました。専用のCopilot指示ファイルにより、AI支援のコントリビューションにも同じ規則が提示されます。
