# Align changelog and AI instructions

**Feature Branch:** work

## Consistent changelog structure

The repository instructions now define localized changelog families, feature branch metadata, detailed change points, and canonical commit links. This lets Cognis reliably discover external module entries and present them in release surfaces.

## Verifiable documentation rules

Documentation tests now handle changelogs separately from standard documentation and validate locale variants, metadata, substantive change details, and commit links. A dedicated Copilot instruction file exposes the same rules to AI-assisted contributions.
