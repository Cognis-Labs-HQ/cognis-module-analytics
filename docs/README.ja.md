# 利用分析

外部の解析サービスを使わず、アカウントの利用状況とモジュールのイベント集計を確認できます。

## できること

管理者はアカウント数、登録の推移、利用期間、記録済みイベントの集計を確認できます。

## 始める前に

モジュールの有効化後に管理者としてログインします。完全なレポートにはデータベースとアカウントサービスが必要です。

## はじめに

Administration の Analytics を開き、集計期間を選んでから更新し、期間に応じたグラフを確認します。
